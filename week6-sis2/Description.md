# Description

## Goal

Automate the five end-to-end test cases from the Week 6 brief against the Toolshop (https://practicesoftwaretesting.com) with Playwright, in a suite that:

- runs green from a clean clone with `npm ci && npx playwright test`;
- is structured: page objects, fixtures, a data factory, no locator in a spec file;
- asserts: every test has at least one assertion that would fail if the feature broke;
- is independent: unique data per run, no test depends on another, passes in parallel and in any order;
- uses no `waitForTimeout`, no CSS-class and no positional-XPath locators.

## Test cases to be automated

| ID | Test case | Steps (summary) | Expected result |
|----|-----------|-----------------|-----------------|
| TC-01a | Register a new customer | Open `/auth/register`, fill all fields with a fresh email, submit; then sign in with the same credentials | Redirect to `/auth/login`, no register error; after sign-in URL is `/account` and the menu shows the new name |
| TC-01b | Register with an existing email | Same form, email `customer@practicesoftwaretesting.com` | Error "already exists" shown, still on `/auth/register` |
| TC-02a | Log in, valid | `/auth/login`, seeded customer, submit | URL `/account`, page title "My account", menu shows "Jane Doe" |
| TC-02b | Log in, invalid | Seeded email, wrong password | Error "Invalid email or password", still on `/auth/login`, no user menu |
| TC-03 | Buy a product | Pick an in-stock product via API, open its page, add to cart, open cart, proceed through sign-in, address and payment (cash on delivery) | Badge "1"; one cart line with the right name, quantity 1, price and total; "Payment was successful" and the order confirmation |
| TC-04a | Compare two products | Open two in-stock products, capture name and price from the UI | Names differ and match the API; UI prices match API prices; the cheaper product is the same in UI and API |
| TC-04b | Two products in one cart | Add both, open cart | Badge "2", two lines, both names present, total = sum of prices |
| TC-05a | Reset password, known email | `/auth/forgot-password`, seeded email, submit | A confirmation alert appears |
| TC-05b | Reset password, invalid email | `not-an-email`, submit | Validation error, still on the forgot-password page |

## Test data

- Seeded customer: `customer@practicesoftwaretesting.com` / `welcome01` (Jane Doe), used read-only.
- New customers: `sis2.<timestamp><random>@example.com`, generated by `data/user.factory.ts` on every run, so repeated and parallel runs never collide.
- Products: whatever the API reports as in stock at run time.

## Tooling

TypeScript, `@playwright/test` 1.49, Chromium. Reporter: list plus HTML, with a screenshot of every test and a trace on the first retry.
